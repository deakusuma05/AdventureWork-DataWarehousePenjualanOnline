SUMBER DATA DAN BATAS PENGUJIAN

Bagian yang sudah diperiksa dan masih perlu diuji

Data snapshot berasal dari ZIP asli.

Agregasi diturunkan dari sql/adventureworks_dw (2).sql, menggunakan join foreign key surrogate. Perangkat pembangun ulang tersedia di scripts/.

Rekonsiliasi detail, pesanan, unit, dan penjualan.

Kedua dump memiliki total fakta identik; hasil filter dihitung ulang dari fakta yang dipilih, bukan dari angka tetap.

Struktur dan historisasi pada ZIP tidak identik dengan DW praktik.

Dump ZIP menyimpan natural key berulang pada beberapa dimensi dan belum memperlihatkan periode SCD Type 2 produk. Snapshot tidak mengklaim SCD2 ZIP sudah benar.

Implementasi Mondrian belum dijalankan pada server lokal.

XML dan MDX telah disediakan serta diperiksa formatnya, namun validasi kueri nyata dan hasil MDX terhadap SQL tetap diperlukan.

Database praktik lokal adalah sumber berbeda.

Mode MySQL lokal bersifat opsional, butuh file koneksi dan database adventureworks_dw_praktik_haura. Jangan mencampur hasilnya dengan snapshot ZIP.

◈Keamanan: snapshot ZIP berisi agregasi data contoh dan tidak memerlukan kredensial. Mode MySQL memakai API PHP serta akun database SELECT-only; jangan menyertakan config.php ketika mengunggah ke GitHub. OLAP Explorer di sini bukan server Mondrian.
