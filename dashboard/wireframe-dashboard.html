SQL & API Specification.

Daftar kueri SQL untuk setiap komponen visual terhadap skema adventureworks_dw (saat ini prototipe menggunakan DW Data Snapshot pada JavaScript).

1. Endpoint: GET /api/kpi/summary (KPI P1, P3, P5) JSON Spec 
SELECT 
    ROUND(SUM(f.line_total), 2) AS total_sales,
    COUNT(DISTINCT f.sales_order_id) AS total_orders,
    COUNT(DISTINCT f.customer_key) AS active_customers,
    SUM(f.order_qty) AS total_units,
    ROUND(SUM(f.line_total) / COUNT(DISTINCT f.sales_order_id), 2) AS aov,
    ROUND(SUM(f.line_total * p.discount_pct), 2) AS est_promo_discount
FROM fact_online_sales f
JOIN dim_promotion p ON f.promotion_key = p.promotion_key;
Output Snapshot: {"total_sales": 29358677.22, "total_orders": 27659, "active_customers": 18484, "total_units": 60398, "aov": 1061.45, "est_promo_discount": 48530.24}
2. Endpoint: GET /api/trends/monthly (Line Chart P1) JSON Spec 
SELECT 
    d.tahun, d.bulan, d.nama_bulan,
    COUNT(DISTINCT f.sales_order_id) AS monthly_orders,
    SUM(f.order_qty) AS monthly_units,
    ROUND(SUM(f.line_total), 2) AS monthly_sales
FROM fact_online_sales f
JOIN dim_date d ON f.tanggal_key = d.tanggal_key
GROUP BY d.tahun, d.bulan, d.nama_bulan
ORDER BY d.tahun, d.bulan;
Menghasilkan 38 baris deret waktu bulanan (Mei 2011 – Juni 2014).
3. Endpoint: GET /api/products/top (Bar Chart P2) JSON Spec 
SELECT 
    p.category_name, p.product_name,
    SUM(f.order_qty) AS units_sold,
    ROUND(SUM(f.line_total), 2) AS sales_amount
FROM fact_online_sales f
JOIN dim_product p ON f.product_key = p.product_key
GROUP BY p.product_key, p.category_name, p.product_name
ORDER BY sales_amount DESC LIMIT 10;
4. Endpoint: GET /api/regions/sales (Bar Chart P4) JSON Spec 
SELECT 
    t.territory_group, t.country_code, t.territory_name,
    COUNT(DISTINCT f.sales_order_id) AS distinct_orders,
    ROUND(SUM(f.line_total), 2) AS sales_amount
FROM fact_online_sales f
JOIN dim_territory t ON f.territory_key = t.territory_key
GROUP BY t.territory_group, t.country_code, t.territory_name
ORDER BY sales_amount DESC;
5. Endpoint: GET /api/promotions/details (Tabel P5) JSON Spec 
SELECT 
    p.description, p.discount_pct,
    COUNT(*) AS items_sold,
    ROUND(SUM(f.line_total), 2) AS sales,
    ROUND(SUM(f.line_total * p.discount_pct), 2) AS est_discount
FROM fact_online_sales f
JOIN dim_promotion p ON f.promotion_key = p.promotion_key
GROUP BY p.promotion_key, p.description, p.discount_pct
ORDER BY sales DESC;
6 & 7. Endpoint: /api/currency/quality & /api/shipping (P6, P7) JSON Spec 
-- P6: Kelengkapan Kurs & Valuta
SELECT c.to_currency_code, COUNT(DISTINCT f.sales_order_id) AS orders_count,
       ROUND(SUM(f.line_total), 2) AS sales_amount
FROM fact_online_sales f JOIN dim_currency c ON f.currency_key = c.currency_key
GROUP BY c.to_currency_code ORDER BY orders_count DESC;

-- P7: Distribusi Metode Kirim
SELECT s.ship_method_name, COUNT(DISTINCT f.sales_order_id) AS total_orders
FROM fact_online_sales f JOIN dim_ship_method s ON f.ship_method_key = s.ship_method_key
GROUP BY s.ship_method_name ORDER BY total_orders DESC;
