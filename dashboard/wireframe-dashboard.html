Kamus Endpoint API & Kueri SQL Data Warehouse (JSON Backend)

Setiap visual mengambil data dari database target adventureworks_dw melalui backend kecil yang mengembalikan format JSON.

1. Endpoint: GET /api/kpi/summary (Menjawab KPI P1, P3, P5) JSON Output 
SELECT 
    ROUND(SUM(line_total), 2) AS total_sales,
    COUNT(DISTINCT sales_order_id) AS total_orders,
    SUM(order_qty) AS total_units,
    ROUND(SUM(line_total) / COUNT(DISTINCT sales_order_id), 2) AS aov,
    ROUND(SUM(unit_price_discount * order_qty * unit_price), 2) AS total_discount
FROM fact_online_sales;
Format Return: {"total_sales": 29358677.22, "total_orders": 27659, "total_units": 60398, "aov": 1061.45, "total_discount": 84320.12}
2. Endpoint: GET /api/trends/monthly (Menjawab Line Chart P1) JSON Output 
SELECT 
    d.year, d.month_number, d.month_name,
    COUNT(DISTINCT f.sales_order_id) AS monthly_orders,
    SUM(f.order_qty) AS monthly_units,
    ROUND(SUM(f.line_total), 2) AS monthly_sales
FROM fact_online_sales f
JOIN dim_date d ON f.date_key = d.date_key
GROUP BY d.year, d.month_number, d.month_name
ORDER BY d.year, d.month_number;
3. Endpoint: GET /api/products/top (Menjawab Bar Chart P2) JSON Output 
SELECT 
    p.category_name, p.product_name,
    SUM(f.order_qty) AS units_sold,
    ROUND(SUM(f.line_total), 2) AS sales_amount
FROM fact_online_sales f
JOIN dim_product p ON f.product_key = p.product_key
GROUP BY p.category_name, p.product_name
ORDER BY sales_amount DESC LIMIT 10;
4. Endpoint: GET /api/regions/sales (Menjawab Bar Chart P4) JSON Output 
SELECT 
    t.territory_group, t.country_code, t.territory_name,
    COUNT(DISTINCT f.sales_order_id) AS distinct_orders,
    ROUND(SUM(f.line_total), 2) AS sales_amount
FROM fact_online_sales f
JOIN dim_territory t ON f.territory_key = t.territory_key
GROUP BY t.territory_group, t.country_code, t.territory_name
ORDER BY sales_amount DESC;
